# Kiribe Online

Premium editorial and entertainment — film, TV, opinion, news, and spotlight features in a magazine-style web platform.

## Problem → solution

Generic blogs don't match a premium media brand. Kiribe Online gives Kiribe a credible editorial presence with strong visuals, simple browsing, and one admin workflow — on infrastructure that stays affordable in year one (Neon, R2, Cloudflare).

## Features (v1 outcomes)

- Homepage with featured stories
- Article pages with rich media
- Archive with search and list/tile views
- Category and tag browsing
- About, Contact, Subscribe
- Single-admin CMS (Payload)
- SEO and analytics hooks
- Caching, rate limiting, offline fallback
- Dev, staging, and production environments

## Tech stack

Next.js 15 · TypeScript · Payload CMS · Neon PostgreSQL · Cloudflare R2 · TanStack Query

## Status

**Foundation scaffold** — June 2026. Phase 1 (Payload, DB, R2) next.
